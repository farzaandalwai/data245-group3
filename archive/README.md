# Immutable original pilot archive

`original_pilot/` preserves all ten downloaded handoff originals byte-for-byte, including the original relative `data_prep_pipeline/`, `data/processed/`, and `results/` layout. Its `README.md` is the original UTF-16 file, not generated instructions. A UTF-8 reading copy remains under `docs/handoff/`.

Do not execute or edit the archive. The raw CSV is absent and ignored. The import manifest records both initial destinations and current archived/working paths; `docs/provenance.md` explains path adaptations. Current working files live under `src/`, `notebooks/`, `data/`, and `results/`. Archive duplication does not create new experimental evidence or change original authorship.
