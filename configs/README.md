# Shared configuration metadata

`dataset.yaml` records fixed inputs and current paths; `experiments.yaml` mirrors the planned chronological design; `models.yaml` records owners and implementation status, while `contract.yaml` is the canonical shared definition. These files are documentation/configuration metadata, not a runnable experiment framework. They do not implement features, eligibility, tuning, or prediction producers.

DELTA proposes data/feature changes; DEVGRU proposes linear-model changes; SAS coordinates shared protocol/evaluation changes. Coordinate before editing shared files. Exact primary allowlists, definitions, file formats, preprocessing, tuning budgets and handoffs are now frozen in `contract.yaml` v1.0.0, with byte hashes in `contract.lock.json`. `contract_frozen: true` refers to definition only. Source/local field audit is recorded separately; producers/models and validation-selected settings are not completed by that flag. Changes require a versioned amendment and lock update. Requirements remain in `requirements.txt`; PyYAML is used only to validate these files in layout tests.
