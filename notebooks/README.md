# Notebooks

`DELTA_data/` contains the path-adapted inherited notebook. `DEVGRU_linear_models/` and `SAS_evaluation/` describe the active owners' future notebook work. Reusable producers belong in `src/`; notebooks may call them after implementation, but are not shared runtime dependencies for other owners.

The working inherited notebook has cleared outputs/execution counters and has not been rerun. The exact original notebook, including historical outputs, is archived. Do not mistake a directory/README for an implemented model.

All new notebooks follow the [approved v2 protocol](../docs/experiment_protocol.md) and [draft interfaces](../docs/interfaces.md). Historical notebook narrative is not current methodology. Keep development/final experiment versions distinct.
