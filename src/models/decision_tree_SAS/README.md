# Decision-tree regression — SAS

Status: implemented, with synthetic checks and real validation on DELTA’s exact development r2 bundle. See [SAS integration](../../../docs/SAS_INTEGRATION.md). See [SAS handoff](../../../docs/SAS_LOCAL_HANDOFF.md). Final/test scoring remains blocked; task branch/draft PR publication is explicitly authorized.

`v2.py` consumes DELTA's exact ordered allowlists and keyed observations. Each condition uses the same ordered grid/budget: depth 3, 5, 8, unlimited crossed with minimum leaf size 5, 20, 50 (12 candidates each). Seed 245, squared-error tree criterion, no imputation/scaling/clipping. Fit every candidate on train only, select by validation MAE, break ties by declared grid order, retain the selected train-fitted candidate without validation refitting. These are explicit development choices in [development_policy.json](development_policy.json), not group-frozen settings or final experiment selections.

Run `python3 -m scripts.sas_v2 train-tree --help`. A trusted bundle manifest SHA-256 is mandatory. Only `development_debugging`/`synthetic_test_only` bundles are accepted. No test predictions are generated. Runs under `results/decision_tree_SAS/v2/<run_id>/` reject overwrite and contain paired predictions, train/validation metrics, all candidate validation scores, selected settings, inspectable tree JSON, provenance and artifact hashes. The trees are exported as numeric inspection data, never executable pickle files.

The exact DELTA development r2 bundle has now been verified and used for a real development run. Final inputs and test scoring are rejected even if external metadata changes its freeze flags; a separately reviewed final workflow is still needed. SAS's evaluator consumes standardized files and does not import the tree implementation.

Authority: [approved V2 protocol](../../../docs/experiment_protocol.md), [draft shared interfaces](../../../docs/interfaces.md), and [DELTA handoff](../../../docs/DELTA_DATA_HANDOFF.md). Upstream API reference: [scikit-learn DecisionTreeRegressor](https://scikit-learn.org/stable/modules/generated/sklearn.tree.DecisionTreeRegressor.html). Optional Random Forest remains deferred until the core comparison works.
